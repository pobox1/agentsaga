# User stories

- As an operator, I can commit a DAG and one maximum USDC budget before work
  starts.
- As a provider, I can submit an independently hashed deliverable and receive
  payment only after the configured evaluator approves it.
- As an evaluator, I can approve or reject a job with a reason/evidence hash.
- As an operator, I can see descendants frozen immediately after a failure.
- As an operator, I can distinguish refund, rollback, and compensation.
- As an auditor, I can read the final receipt directly from Arc without the
  backend.
